Publish a plugin

플러그인 등록하기

플러그인 코드는 각자의 public GitHub 레포에 두고, dap-plugins 레포의 plugin_catalog.json에 포인터를 추가하는 방식으로 등록합니다.

  1. 공개 GitHub 레포 루트에 manifest v2 plugin.yaml과 자기완결 .mjs 진입 파일을 준비합니다.
  2. 플러그인 version을 올리고 태그를 만든 뒤, README에 권한 이유와 플랫폼 제한을 기록합니다.
  3. manifest id와 같은 id, 레포와 고정 ref를 dap-plugins 카탈로그에 추가해 PR을 보냅니다.
id
필수 · plugin.yaml과 정확히 같은 고유 ID
repo
필수 · 공개 GitHub owner/name 또는 URL
name
선택 · 카탈로그 표시 이름
description
선택 · 한 줄 기능 설명
category
선택 · productivity, utility, developer
ref
선택 · 태그 권장, 브랜치 또는 SHA 가능
