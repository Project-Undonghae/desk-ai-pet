Publish a plugin

플러그인 등록하기

플러그인 코드는 각자의 public GitHub 레포에 두고, dap-plugins 레포의 plugin_catalog.json에 포인터를 추가하는 방식으로 등록합니다.

  1. 플러그인 레포에 plugin.yaml과 진입 파일을 준비합니다.
  2. README에 설치 방법, 권한 범위, 사용 예시를 정리합니다.
  3. dap-plugins의 plugin_catalog.json에 필요한 정보를 추가해 PR을 보냅니다.
id
고유 플러그인 ID
name
마켓플레이스 표시 이름
description
한 줄 기능 설명
category
productivity, utility, developer 중 하나
repo
GitHub 저장소 경로
ref
설치에 사용할 브랜치 또는 태그
