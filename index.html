HOW IT WORKS

01
다운로드 & 설치

위 버튼으로 플랫폼에 맞는 파일을 받아 실행. 부팅 자동 시작 등록도 선택 가능.

02
AI 연결

설정에서 Claude · ChatGPT · Gemini 중 선택 후 API Key 입력. OS 키체인에 안전 저장.

03
단축키로 즉시 호출

Ctrl+Shift+Space (Win) / Cmd+Shift+Space (Mac) 어디서든 AI 채팅 팝업.
