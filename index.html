DAP overview

DAP은 바탕화면 위 고양이로 시작하는 AI OS입니다

DAP v1.4.1은 화면 위 고양이와 Todo·Calendar, 데일리 브리핑, 빠른 실행과 미니 채팅을 한곳에 모읍니다. Google Calendar를 연결하고 Gmail 상태 안내를 받아 필요한 정보와 작업을 흐름을 끊지 않고 이어갈 수 있어요.

Core features

CMD

빠른 실행

Windows에서는 Ctrl+Shift+Space, macOS에서는 Cmd+Shift+Space로 어디서든 실행창을 열어 DAP에게 요청합니다.

AI

Claude/Codex 연결

이미 로그인한 Claude 또는 Codex를 연결해, 따로 API Key를 입력하지 않고 바로 사용할 수 있습니다.

SEL

QUICK ACTIONS

개선된 드래그 선택으로 텍스트를 잡으면 커서 근처에 빠른 액션 바가 안정적으로 열립니다. 다듬기, 번역, 요약, 질문과 웹 검색을 바로 실행하세요.

PET

PET INTERFACE

고양이가 투명 오버레이로 화면 위에 머물며 작업, 생각, 오류, 기쁨 같은 상태를 조용히 보여줍니다.

Current in v1.4.1

PLAN

Todo와 Calendar

할 일은 리스트와 칸반으로 정리하고 일정은 월·주 캘린더로 확인합니다. 붙여넣은 글·이미지·메일에서 초안을 만들어 확인 후 등록할 수도 있어요.

LINK

서비스 연결과 상태 안내

Calendar는 DAP이 관리하는 OAuth로 Google 계정을 연결합니다. Todo는 Gmail 커넥터가 없을 때 필요한 연결 방법을 안내합니다.

AM

데일리 브리핑

원할 때 기능을 켜고 시간을 정하면 Todo와 Calendar가 오늘의 할 일과 일정만 짧게 모아 한 번에 전합니다.

TRAY

미니 채팅과 트레이 허브

DAP 아이콘을 왼쪽 클릭하면 같은 대화 기록을 쓰는 미니 채팅이, 오른쪽 클릭하면 상태·설정·플러그인을 모은 트레이 허브가 열립니다.

LIVE

Weather와 Meeting Assistant

관심 도시의 현재 날씨와 3일 예보를 확인하고, 회의에서는 실시간 전사·번역, AI 답변 추천, 요약과 종료 리포트를 활용할 수 있습니다.

IMG

AI 이미지와 더 나은 드래그 선택

Meme Vault에서 AI 이미지를 만들고 보관하세요. 개선된 텍스트 드래그 선택은 커서 가까이에 빠른 액션을 안정적으로 띄워줍니다.

자주 묻는 질문

DAP은 무엇인가요?

DAP(Desk AI Pet)은 Windows/macOS 바탕화면 위에 머무는 데스크톱 AI 펫입니다.

변경 작업은 바로 실행되나요?

아니요. 파일 변경이나 화면 제어 같은 실행 작업은 범위와 내용을 먼저 보여주고 사용자 확인을 받은 뒤 진행합니다.

별도 설정이 많이 필요한가요?

기본 흐름은 별도 API Key 입력이 아니라, 이미 로그인한 Claude/Codex를 연결해 사용하는 방식입니다.

플러그인을 만들거나 등록할 수 있나요?

플러그인 페이지에서 DAP에 더해 쓸 수 있는 확장 기능을 둘러볼 수 있습니다.
