# 릴리스 상태와 플랫폼 지원

확인일: 2026-11-16. 앱 소스 기준: `Project-Undonghae/mydeskpet`의 v1.7.1 릴리스 커밋.

## 정식 버전

공개 안정판은 **v1.7.1**이며 **macOS Apple Silicon 전용**입니다. 이 릴리스에는 Windows 설치 파일이 없고, **Windows 버전은 준비 중**입니다. v1.7.0은 공개되지 않은 초안으로 남았습니다.

v1.7.1에서 Workspace와 같은 작업창에 **DAP Crew**가 들어왔습니다.

- 작업창에서 Workspace와 Crew를 오갑니다. Crew의 + 메뉴에서 설치해 둔 Claude Code·Codex·Antigravity나 셸 터미널을 프로젝트마다 열고, 탭과 분할 화면으로 배치합니다.
- Crew의 파일 보기는 Markdown과 이미지를 그려 보여 주고, 큰 파일은 이어서 읽습니다. diff 줄 코멘트는 고른 AI의 입력창에 넣기만 하고 보내지 않습니다.
- 치운 작업은 보관함으로, 지운 작업은 휴지통에 30일 동안 남고 복원·영구 삭제·휴지통 비우기를 할 수 있습니다.
- Workspace의 변경 화면(커밋 안 된 변경·diff·모두 커밋), 턴별 되돌리기, Claude Code 대화의 권한 방식 바꾸기, 답을 쓰는 동안 쌓이는 요청 줄, 대화 옆 터미널(Control+`), 작업트리에서 시작하는 대화.
- 설정 > 일반 > 언어(시스템 따르기·한국어·English, 다음 시작부터 적용), 설정 > 알림(Workspace와 Crew 공용).
- Claude와 Codex는 기본 로그인 외 계정을 추가할 수 있습니다. macOS에서 Claude 계정 추가는 Claude CLI 2.1.319 이상이 필요합니다.

다른 기기에 SSH로 연결하는 Crew 원격 작업은 이 릴리스에 들어 있지 않습니다. 모든 제공자의 실사용 검증 완료나 입력 보호·원본 화면 복구 실험을 출시 기능으로 안내하지 않습니다. Workspace·Crew의 내부 기능을 데스크톱 `plugin.yaml` / `ctx.host.*` API 계약으로 확대하지 마세요. 데스크톱 Plugin Platform 0.4 / manifest v2 계약은 그대로입니다.

## 플랫폼 지원

- 웹사이트는 macOS Apple Silicon 다운로드만 링크합니다. Windows 버튼은 링크 없이 "준비 중"으로 표시합니다.
- **v1.6.26은 마지막 macOS Intel(x64) 릴리스**입니다. 이후 Intel 패키지는 만들지 않습니다.
- 자동 동기화는 arm64 DMG와 SHA-256만 필수로 요구합니다. Windows EXE가 있으면 함께 게시하고, 없으면 새 버전의 다운로드·체크섬에 Apple Silicon만 기록하며 최신 Windows 링크를 뺍니다. Intel DMG가 없는 릴리스도 동기화할 수 있습니다.
- 릴리스에 오래된 Intel 파일이 있어도 활성 다운로드·해당 최신 버전 메타데이터에는 다시 추가하지 않습니다.
- 이전 버전의 기록과 기존 GitHub 릴리스 파일은 보존합니다. 공개 릴리스 파일 자체를 삭제하거나 과거 체크섬을 수정하지 않습니다.
- 초안·사전 공개 릴리스는 안정판 동기화에서 계속 거절합니다.

Windows 버전을 다시 내는 시점에는 정식 릴리스와 실제 산출물을 확인하고, 다운로드 버튼·플랫폼 안내·관련 문서를 함께 갱신합니다.
