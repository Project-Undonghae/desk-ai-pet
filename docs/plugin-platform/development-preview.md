# 개발 미리보기와 플랫폼 지원

확인일: 2026-11-19. 개발 소스 기준: `Project-Undonghae/mydeskpet` dev 브랜치 커밋 `0ef24cb`.

## 정식 버전과 개발 상태

**v1.7.1은 아직 공개되지 않은 다음 공개 후보**이며 공개 설치본이 없습니다. 웹사이트는 다운로드 대신 웨이팅리스트를 안내하고, 실제 산출물이 공개되기 전까지 설치 링크를 제공하지 않습니다.

개발 브랜치에는 다음 작업이 통합돼 있습니다.

- Workspace / Crew 전환 중 진행 중인 실행, 입력 초안과 프로젝트 작업 기록 유지.
- Claude·Codex·Antigravity 제공자별 여러 계정 등록과 Workspace/Crew별 계정 고정. 다른 계정으로 조용히 자동 전환하지 않음.
- Crew 프로젝트, worktree, 파일, Git, 터미널, CLI 모델과 메인 오케스트레이터 연결.
- Markdown, DOCX, HWPX, XLSX, PPTX, HTML/CSS/JS 미리보기·편집기와 인앱 브라우저를 포함하는 Document Workspace.
- 방해 금지, 이전 실행, 오프라인 이후에도 관련 세션을 다시 여는 완료 알림.
- 기존 Feyn 학습 흐름과 데스크톱 파트너 경험 유지.

네이티브 Workspace 재구축과 Office 네이티브 미리보기 일부는 준비 중입니다. 전체 제공자/OS 조합의 실사용 검증 완료나 모든 실험 기능의 기본 활성화를 주장하지 않습니다. 앱 종료 후 기존 작업을 임의로 재실행하지 않는다는 배포 경계를 유지합니다.

개발 브랜치의 소스 통합은 공개 설치본, 서명·공증 또는 배포 완료를 의미하지 않습니다. 이 미리보기를 데스크톱 `plugin.yaml` / `ctx.host.*` API 계약으로 확대하지 마세요.

## 다음 공개 빌드와 플랫폼

다음 공개 빌드는 **macOS Apple Silicon(arm64)**부터 준비합니다. Windows 후속 공개 일정은 아직 확정되지 않았습니다. **v1.6.26은 마지막 macOS Intel(x64) 공개 릴리스**입니다.

- 웹사이트에는 공개 설치 파일이 나오기 전까지 다운로드 버튼을 표시하지 않습니다.
- 웨이팅리스트는 사이트 입력 폼이 아니라 공식 이메일 앱을 여는 방식이며, 사이트가 주소를 수집하거나 저장하지 않습니다.
- 공개 시 실제 플랫폼, 서명·공증과 체크섬을 다시 확인합니다.
- 이전 버전의 기록과 기존 GitHub 릴리스 파일은 보존합니다. 공개 릴리스 파일 자체를 삭제하거나 과거 체크섬을 수정하지 않습니다.
- 초안·사전 공개 릴리스는 안정판 동기화에서 계속 거절합니다.

공개 시점에는 정식 릴리스와 실제 산출물을 다시 확인하고, 웨이팅리스트·개발 미리보기·플랫폼 안내·관련 API 문서를 함께 갱신합니다.
