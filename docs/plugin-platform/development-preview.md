# 개발 미리보기와 플랫폼 지원

확인일: 2026-11-04. 개발 소스 기준: `Project-Undonghae/mydeskpet` 커밋 `9b4d72b941`.

## 정식 버전과 개발 상태

현재 공개 안정판은 [v1.6.26](https://github.com/Project-Undonghae/desk-ai-pet/releases/tag/v1.6.26)입니다. **v1.7.0은 공개되지 않은 개발 체크포인트**이며 공개 설치본이 없습니다. 웹사이트의 다운로드와 버전 메타데이터는 정식 릴리스를 기준으로 유지합니다.

개발 브랜치에는 다음 작업이 통합돼 있습니다.

- 작업창 상단에서 Workspace / Crew 전환. 화면 전환·숨김·최소화 중 진행 중인 실행과 입력 초안을 유지하는 흐름.
- 현재 친구와 연결된 Claude·Codex·Antigravity 구독 모델 선택 및 기존 CLI 로그인 재사용.
- 친구의 말투·개인 기억을 이어가면서 업무 기록은 프로젝트별로 관리.
- 프로젝트·최근 목록·worktree·파일/코드·Git·터미널·협업 전달과 기존 Feyn 학습 흐름.
- Workspace 시작 시간 초과와 재시도 보완.

Core 연결과 일부 협업은 미리보기입니다. 전체 Herdr 기능 동등성·원격 SSH·모든 제공자/OS의 실사용 검증 완료를 주장하지 않습니다. 별도로 개발된 입력 보호·원본 화면 복구 실험이 모두 다음 설치본의 기본 기능으로 활성화됐다고 해석하지 않습니다. 앱 종료 후 기존 작업을 임의로 재실행하지 않는다는 배포 경계를 유지합니다.

본체의 `docs/project/qa/dap-crew-1.7.0-release.md`는 코드 병합과 소스 검증을 기록하지만, 초안 패키징을 정식 서명·공증·공개 완료로 표시하지 않도록 구분합니다. 이 미리보기를 데스크톱 `plugin.yaml` / `ctx.host.*` API 계약으로 확대하지 마세요.

## Intel Mac 신규 제공 종료

사용자 결정과 현재 패키징 설정에 따라 신규 배포 대상은 **Windows와 macOS Apple Silicon(arm64)**입니다. **v1.6.26은 마지막 macOS Intel(x64) 릴리스**이며 v1.7.0부터 Intel 패키지를 만들지 않습니다.

- 웹사이트에는 Windows와 Apple Silicon 다운로드만 표시합니다.
- 자동 동기화는 Windows EXE와 arm64 DMG·SHA-256만 요구합니다. Intel DMG가 없는 릴리스도 동기화할 수 있습니다.
- 릴리스에 오래된 Intel 파일이 있어도 활성 다운로드·해당 최신 버전 메타데이터에는 다시 추가하지 않습니다.
- 이전 버전의 기록과 기존 GitHub 릴리스 파일은 보존합니다. 공개 릴리스 파일 자체를 삭제하거나 과거 체크섬을 수정하지 않습니다.
- 초안·사전 공개 릴리스는 안정판 동기화에서 계속 거절합니다.

공개 시점에는 정식 릴리스와 실제 산출물을 다시 확인하고, 개발 미리보기 표시·플랫폼 안내·관련 API 문서를 함께 갱신합니다.
