# DAP Workspace · 1.6.25 / 1.6.26

DAP Workspace는 기존 DAP의 Claude/Codex CLI 로그인과 실행기를 재사용하는 작업창입니다. 대화·세션·도구·플러그인·자동화와 실행 승인·취소를 한 화면에서 다룹니다. 창을 최소화하거나 닫으면 바탕화면 펫으로 돌아갑니다.

공개 안정판 [v1.6.25](https://github.com/Project-Undonghae/desk-ai-pet/releases/tag/v1.6.25)와 [v1.6.26](https://github.com/Project-Undonghae/desk-ai-pet/releases/tag/v1.6.26)을 기준으로 합니다.

## 시작과 연결

- Workspace에서 세션을 열고 요청을 입력합니다. 입력창의 작은 에이전트 표시와 기존 DAP 설정에서 Claude/Codex 연결을 관리합니다.
- 기존 CLI 인증과 대화 저장 위치를 유지합니다. Claude를 사용하려면 해당 Claude CLI 로그인이 필요합니다.
- Workspace 안에서도 펫 모션과 작업 중인 Codex·Claude 상태를 표시합니다.

## 세션과 도구

세션을 프로젝트 사이로 이동하고, 다른 대화에 세션 참조를 첨부할 수 있습니다. 세션 삭제와 복원을 지원합니다. 도구 실행의 승인 요청을 확인하고 진행 중인 작업을 취소할 수 있습니다.

agent-desktop, REA, Ghidra와 Java를 설치본에 포함합니다. 데스크톱 작업과 바이너리 분석에 필요한 이 도구들을 별도로 설치하지 않아도 됩니다.

공식 릴리스는 Windows에서 실제 대화·승인 후 화면 조작·결과 확인·세션 정리와 Ghidra 분석을 검증했다고 안내합니다. macOS는 서명·아키텍처·JNA 로드를 확인했으며, 데스크톱 도구의 실기기 화면 조작 검증은 후속 과제로 남아 있습니다.

사주·운세 및 다마고치 돌보기 비용은 이 Workspace 구성에서 제외됩니다. 기존 사용자 설정과 대화는 유지합니다.

## 1.6.26 시작 오류와 다시 시작

번들 플러그인을 처음 준비하는 시작 대기 한도는 3분입니다. 시작에 실패하면 원래 오류와 **다시 시작** 버튼을 표시합니다. 재시도는 소유한 기존 프로세스 종료와 재연결을 기다려 중복 실행을 막습니다.

오류가 계속되면 화면에 표시된 원래 오류와 앱 버전을 확인하세요. CLI 인증과 사용자 데이터 경로를 지우는 것을 첫 해결책으로 삼지 않습니다.

## 기존 앱 카탈로그·개발 계약

데스크톱 앱 카탈로그의 `plugin.yaml`, `activate(ctx)`, `ctx.host.*`와 Plugin Platform 0.4 / manifest v2 계약은 별도로 유지합니다. 기존 palette/tray 앱 화면은 [App UI System v1](app-ui.md)을 따릅니다. Workspace 내부 기능이 모두 이 데스크톱 플러그인 API에 추가된 것으로 해석하거나 존재하지 않는 Host API를 만들지 마세요.

v1.6.26 카탈로그에는 앱 카드용 선택 필드 `icon`이 문서화돼 있습니다. 저장소 안 상대 경로를 사용하며 PNG/JPG/WebP/SVG/ICO, 512KB 이하를 권장합니다. 없거나 읽을 수 없으면 앱 이름 첫 글자로 표시합니다. `ctx.radialMenu.addItem()`의 항목별 아이콘과는 별도입니다.

근거: 공개 릴리스 노트와 본체 `v1.6.26` 태그의 `docs/PLUGIN_API.md`. 이후 개발 브랜치의 미출시 기능은 포함하지 않습니다.
