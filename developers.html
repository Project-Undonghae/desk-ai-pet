DAP Plugin Platform

DAP Plugin Docs

DAP 플러그인은 데스크톱 위의 DAP 경험에 명령, 액션, 설정, 단축키, 팔레트 UI, 로컬 서비스를 추가하는 확장 모듈입니다. 이 문서는 실제 플러그인을 만들고 배포하는 데 필요한 최소 경로와 API 레퍼런스를 제공합니다.

문서/버전 기준

현재 Plugin Platform은 0.2.0, 최소 호환 앱은 DAP >=v1.3.9입니다. manifest 안정 계약은 manifest_version: 2를 유지하며, 기존 0.1.x 호환성 기록도 보존합니다.

Overview

DAP 플러그인은 plugin.yaml과 자기완결 ESM .mjs 진입 파일로 구성됩니다. manifest에는 메타데이터와 권한만 선언하고, 기능 등록은 activate(ctx)에서 수행합니다.

현재 런타임

현행 DAP 플러그인 문서는 DAP v1.3.9 이상의 Electron/TypeScript Host API를 기준으로 합니다. manifest v2 필드 집합과 해석 규약은 stable contract이며, 예전 Python/PyQt 플러그인 문서는 historical 문서로만 취급합니다.

Quickstart

1. 폴더 만들기

my-plugin/
  plugin.yaml
  dap_my_plugin/
    plugin.mjs
  README.md

2. manifest 작성

id: com.example.my_plugin
name: My Plugin
version: 1.0.0
manifest_version: 2
entry: dap_my_plugin.plugin:activate
description: DAP에서 실행되는 첫 플러그인
author: Your Name
min_app_version: "1.3.9"
surface: user
permissions: []
execution_modes:
  - user

3. 액션 등록

// dap_my_plugin/plugin.mjs
export function activate(ctx) {
  ctx.actions.registerAction({
    id: "hello",
    callback: () => {
      ctx.host.bubble.speak("Hello from plugin");
      return "Hello from plugin";
    },
  });

  ctx.radialMenu.addItem({
    itemId: "hello",
    label: "Hello",
    actionId: "hello",
    priority: 50,
  });
}

4. 로컬 설치

Windows:
%APPDATA%\dap\plugins\com.example.my_plugin\

macOS:
~/Library/Application Support/dap/plugins/com.example.my_plugin/

DAP을 재시작하거나 설정의 플러그인 토글을 다시 켜서 로드합니다.

Core concepts

개념설명
Manifestplugin.yaml. id, 이름, 버전, entry, 권한을 선언합니다.
Entrymodule.path:activate. 플러그인의 ESM 진입점입니다.
ActivationDAP가 플러그인을 로드할 때 activate(ctx)를 호출합니다.
Registration액션, 메뉴, 단축키, 설정 섹션은 등록 핸들로 추적되고 비활성화 시 역순으로 자동 정리됩니다.
Cleanup타이머·리스너·열린 창처럼 플러그인이 소유한 자원은 activate(ctx)에서 cleanup 함수를 직접 반환해 정리합니다.
Host services클립보드, 저장소, 팔레트 창, LLM 같은 기능은 ctx.host.*로만 접근합니다.
Permissions민감하거나 권한이 필요한 host service는 permissions[]에 선언합니다.

Guides

명령 등록하기

채팅 또는 스팟라이트 입력을 자연어로 라우팅해야 할 때 ctx.commands를 사용합니다.

ctx.commands.addCommand({
  id: "weather",
  title: "날씨",
  matchers: [
    { type: "keyword", patterns: ["날씨", "weather"], priority: 40 },
  ],
  backend: { type: "builtin", handler: "dap.weather.current" },
});

설정 섹션 추가하기

ctx.settings.registerSettingsSection({
  sectionId: "general",
  title: "My Plugin",
  spec: {
    fields: [
      { key: "compact", label: "간단히 보기", type: "toggle", default: false },
      { key: "mode", label: "모드", type: "select", default: "fast",
        options: [
          { value: "fast", label: "빠르게" },
          { value: "careful", label: "정교하게" },
        ] },
      { key: "note", label: "메모", type: "text" },
    ],
  },
});

const values = ctx.host.settings.values("general");

팔레트 UI 열기

팔레트는 플러그인 전용 HTML UI입니다. 페이지는 권한 API를 직접 받지 않고 window.dapPalette 메시지 브리지만 사용합니다.

export function activate(ctx) {
  let palette = null;

  const open = () => {
    if (palette) {
      palette.toggle();
      return;
    }

    palette = ctx.host.windows.openPalette({
      page: "palette/index.html",
      width: 360,
      height: 520,
      frame: false,
    });

    palette.onMessage((msg) => {
      if (msg.type === "ready") {
        palette.postMessage({ type: "items", items: ["A", "B"] });
      }
    });

    palette.show();
  };

  ctx.actions.registerAction({ id: "openPalette", callback: open });
  ctx.radialMenu.addItem({ itemId: "palette", label: "Palette", actionId: "openPalette" });

  return () => palette?.close();
}

AI 대화 컨텍스트 기여하기

manifest에 기여자 id를 먼저 선언하고 같은 id로 ctx.aiContext.contribute()를 등록합니다. 미선언 id는 활성화 실패로 처리됩니다.

# plugin.yaml
context_contributors:
  - recent_items

// plugin.mjs
ctx.aiContext.contribute({
  id: "recent_items",
  provider: async () => "최근 항목 3건: …",
});

provider는 대화 턴마다 호출됩니다. 약 300ms 안에 응답하는 요약 한두 줄만 반환하세요. 지연·예외·길이 초과 결과는 해당 턴에서 생략되거나 잘립니다.

트레이 하위 메뉴 갱신하기

const tray = ctx.trayMenu.addItem({
  itemId: "usage",
  label: "AI 사용량",
  actionId: "openPalette",
  submenu: [{ itemId: "loading", label: "불러오는 중…", enabled: false }],
});

tray.update({ submenu: [
  { itemId: "today", label: "오늘 25%", actionId: "openPalette", enabled: true },
  { itemId: "separator", type: "separator" },
  { itemId: "details", label: "상세 보기…", actionId: "openPalette", enabled: true },
] });

등록 핸들의 update()는 자신이 소유한 항목만 바꾸며 dispose 후에는 무시됩니다. 하위 메뉴는 라벨·separator·action으로만 구성하고, 최대 16행·라벨 160자 제한을 지킵니다.

민감한 Host 기능은 가용성 확인하기

const capability = ctx.host.meeting?.capabilities();
if (!capability?.available) {
  ctx.host.bubble.speak(capability?.reason ?? "회의 캡처를 사용할 수 없어요.");
  return;
}

await ctx.host.meeting.start({
  source: "both",
  sourceLanguage: "en",
  targetLanguage: "ko",
});

meeting.capture는 운영체제 권한과 backend 상태에 따라 비활성일 수 있으므로 항상 capabilities()를 확인합니다. 발표 오버레이는 ctx.host.presentation, 계정·사용량 표시는 ctx.host.aiAccounts를 사용하며 각각 전용 권한이 필요합니다. 토큰·쿠키·원본 인증 출력은 플러그인에 제공되지 않습니다.

API reference

Manifest fields

필드필수설명
id예플러그인 고유 id. 카탈로그 id와 같아야 합니다.
name예사용자에게 표시할 이름입니다.
version예플러그인 버전입니다.
entry예module.path:callable 형식의 진입점입니다.
description, author아니요사용자에게 표시할 설명과 작성자입니다.
min_app_version아니요플러그인의 최소 DAP 버전입니다. 새 0.2 API를 쓰면 1.3.9를 기준으로 합니다.
manifest_version권장현행 안정 계약은 2입니다.
surface아니요user(기본) 또는 dev build에서만 발견되는 dev입니다.
context_contributors아니요ctx.aiContext로 등록할 기여자 id 목록입니다.
surface_slots아니요선언용 표면 메타데이터입니다. 현재 런타임은 사용하지 않습니다.
permissions아니요사용할 권한 토큰 목록입니다.
execution_modes아니요user, builtin 등 배포·실행 형태 메타데이터입니다.

위 필드 외의 추가 필드는 안정 manifest 스키마가 거절합니다.

Host services

권한서비스설명
권한 불필요ctx.host.clipboard현재 클립보드 텍스트를 읽고 쓸 수 있습니다.
권한 불필요ctx.host.bubble, ctx.host.events펫 말풍선과 behavior 이벤트를 사용합니다.
권한 불필요ctx.host.hotkey수동 전역 단축키를 등록·해제합니다.
권한 불필요ctx.host.llm활성 LLM provider로 한 번의 텍스트를 생성합니다.
권한 불필요ctx.host.settings이 플러그인 설정 섹션의 저장값을 읽습니다.
storage.privatectx.host.storage플러그인 전용 격리 저장소입니다.
window.palettectx.host.windows플러그인 팔레트 창을 엽니다.
clipboard.historyctx.host.clipboardHistory클립보드 기록을 읽습니다. 사용자 opt-in이 필요합니다.
input.synthesizectx.host.paste이전 foreground 앱에 붙여넣습니다.
dragdrop.exportwindow.dapPalette drag API팔레트에서 이미지·파일을 OS 드래그로 내보냅니다.
presentation.overlayctx.host.presentation플러그인 HTML을 샌드박스 발표 오버레이에 표시합니다.
meeting.capturectx.host.meeting회의 캡처 상태·전사 이벤트를 제공합니다. capabilities() 확인이 필수입니다.
ai.accountsctx.host.aiAccounts표시용 AI 계정·사용량 메타데이터와 계정 설정 연결을 제공합니다.

clipboard.read/clipboard.write는 설치 고지용 토큰이며 legacy ctx.host.clipboard 노출을 게이트하지 않습니다. 권한은 사용자 동의와 Host API 노출 경계이며 프로세스 sandbox 보안 경계가 아니므로 공식 검토 카탈로그의 플러그인만 설치하세요.

발표·회의·AI 계정 API

  • ctx.host.presentation: openOverlay, closeOverlay, showOverlay, hideOverlay, setInteractive, postMessage, onMessage, cursorPos. 오버레이 페이지에는 window.dapPresentation 메시지/닫기 브리지만 노출됩니다.
  • ctx.host.meeting: capabilities, start, stop, onStatus, onTranscript. 현재 공개 Host는 전사 backend가 연결되기 전까지 available: false를 반환하므로 가용성 검사가 필수입니다.
  • ctx.host.aiAccounts: getOverview, getAccountUsage, addAccount, openAccounts. 플러그인은 표시용 계정·한도 정보만 받고 연결·기본 provider 변경은 DAP와 provider의 기존 UI에서 완료합니다.

onMessage, onStatus, onTranscript가 반환하는 해제 함수를 호출하고 열린 창/세션을 activate(ctx) cleanup에서 정리하세요.

  const list = document.getElementById("list");

  window.dapPalette.onMessage((msg) => {
    if (msg.type !== "items") return;
    list.innerHTML = "";
    for (const item of msg.items) {
      const li = document.createElement("li");
      li.textContent = item;

Versioning

DAP 앱 릴리스 버전, Plugin Platform 버전, manifest 버전, 개별 플러그인 버전은 서로 다른 책임을 가집니다. 플러그인 개발자에게 영향을 주는 변경은 개발문서와 docs/plugin-platform 아래의 관리 파일을 함께 갱신합니다.

변경필수 갱신버전 처리
새 host API, permission, manifest 선택 필드API reference, changelog, version.jsonPlugin Platform minor
API 설명 보강, 예시 수정, 비호환 없는 오류 수정관련 문서, changelogPlugin Platform patch
API 제거, 인자 변경, 권한 필수화, manifest 필수 필드 변경문서 전체, migration note, changelogPlugin Platform major 또는 manifest_version 증가
카탈로그 필드 추가/변경Distribution, plugins.html 등록 안내, fallback dataPlugin Platform minor 또는 major
개별 플러그인 등록/업데이트카탈로그 ref, 필요 시 plugins.html fallback개별 플러그인 버전
  • docs/plugin-platform/version.json은 Plugin Platform의 현재 버전과 호환성 기준입니다.
  • docs/plugin-platform/changelog.md는 앱 릴리스 노트와 별도로 플러그인 개발자용 변경사항을 기록합니다.
  • manifest_version은 manifest 해석 방식이 호환되지 않을 때만 올립니다.

0.2.x의 최소 기준은 DAP >=v1.3.9입니다. 기존 0.1.x/DAP >=v1.0.12 기록은 호환성 이력으로 유지됩니다.

Troubleshooting

증상확인할 것
플러그인이 보이지 않음설치 폴더명, plugin.yaml 위치, id 일치 여부를 확인합니다.
활성화 실패entry가 실제 .mjs named export를 가리키는지 확인합니다.
host service가 undefined필요한 권한을 permissions[]에 선언했는지 확인합니다.
팔레트가 열리지 않음window.palette 권한과 page 경로가 플러그인 루트 안인지 확인합니다.
AI 컨텍스트 등록 실패context_contributors에 provider id를 먼저 선언했는지 확인합니다.
회의 캡처가 시작되지 않음meeting.capture 권한과 OS 권한을 확인하고 capabilities().available이 true인지 확인합니다.
